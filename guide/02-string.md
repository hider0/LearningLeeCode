# 第 2 章：字符串

## 本章目标

- 理解 Python 字符串不可变，修改时通常要创建新字符串或列表；
- 掌握左右双指针和滑动窗口；
- 识别“连续子串”与“前缀”问题；
- 正确处理空串、大小写和非字母数字字符。

## 1. 字符串题的四类信号

| 题目描述 | 常见方法 |
|---|---|
| 从两端比较、判断对称 | 对撞双指针 |
| 原地或逆序处理 | 左右交换 |
| 最长/最短连续子串 | 滑动窗口 |
| 多个字符串从开头相同 | 前缀逐步缩短 |

## 2. 对撞双指针模板

```python
left = 0
right = len(text) - 1
while left < right:
    if text[left] != text[right]:
        return False
    left += 1
    right -= 1
return True
```

如果题目要求忽略标点和大小写，可以先预处理，也可以在指针移动时跳过无效字符。初学阶段建议先预处理，逻辑更容易验证；熟练后再做原地扫描优化空间。

## 3. 滑动窗口的直觉

滑动窗口维护一段连续区间 `[left, right]`。右端负责加入新元素，左端负责在条件被破坏时移除旧元素。

通用步骤：

1. 右指针向右扩张；
2. 更新窗口内的计数或最后位置；
3. 条件不满足时移动左指针；
4. 条件恢复后更新答案。

```python
left = 0
for right, char in enumerate(text):
    # 把 char 加入窗口
    while 窗口不合法:
        # 移除 text[left]
        left += 1
    answer = max(answer, right - left + 1)
```

无重复字符最长子串可以用“最近出现下标”让 left 一步跳到正确位置。注意 left 只能向右，不能因为旧记录而后退。

## 4. 题目阶梯

1. **反转字符串**：练习左右交换和循环边界。
2. **验证回文串**：加入字符过滤与大小写处理。
3. **最长公共前缀**：学习候选答案逐步缩短。
4. **无重复字符的最长子串**：完整滑动窗口。

## 5. 最长公共前缀为什么可以缩短

公共前缀一定是第一个字符串的前缀。先把第一个字符串当候选答案，再用后续字符串不断否定过长的尾部。候选只会缩短，因此不会来回重复搜索。

```python
prefix = strings[0]
for text in strings[1:]:
    while not text.startswith(prefix):
        prefix = prefix[:-1]
return prefix
```

空数组和候选变空是两个重要边界。

## 6. 常见错误

- 把 `while left < right` 写成 `left <= right`，导致中间字符被重复处理；
- 滑动窗口只收缩一次，使用 `if` 而不是需要的 `while`；
- 更新答案的时机错误，在窗口仍不合法时计算长度；
- 最近下标来自窗口左侧，却让 left 向后退；
- 假设输入一定非空，直接读取 `strs[0]`。

## 7. 调试方法

对滑动窗口打印四项信息：

```python
print(left, right, text[left:right + 1], last_seen)
```

拿 `abba` 手动模拟。如果扫描第二个 `b` 后 left 跳到 2，随后遇到最后的 `a` 时 left 不应退回 1。
