# 第 6 章：动态规划

## 本章目标

- 理解动态规划不是背公式，而是保存重复子问题；
- 掌握状态定义、转移方程、初始值和遍历顺序；
- 能从暴力递归推导 DP；
- 学会一维空间压缩。

## 1. 什么时候考虑 DP

一个问题适合动态规划，通常同时具备：

- 大问题可以拆成规模更小的同类问题；
- 不同路径会重复计算相同子问题；
- 当前决策之后，只需要子问题结果，不需要完整历史。

如果你能写出递归，但发现同一个参数组合被反复调用，就应考虑记忆化搜索或 DP。

## 2. DP 四步法

### 第一步：定义状态

必须用一句完整的话描述，例如：

> `dp[i]` 表示到达第 i 级台阶的方法数。

如果状态含义模糊，后面的公式很容易写错。

### 第二步：写转移

思考“最后一步从哪里来”。爬楼梯到第 i 级，最后一步来自 i-1 或 i-2：

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

### 第三步：确定初始值

初始值必须符合状态定义，而不是凭感觉填写。很多 DP bug 都来自 `dp[0]` 的含义不清。

### 第四步：确定遍历顺序

计算当前状态前，它依赖的状态必须已经算好。普通线性 DP 从小到大；某些背包问题还需要特别区分正序和倒序。

## 3. 题目阶梯

1. **爬楼梯**：认识一维状态和滚动变量。
2. **打家劫舍**：练习“选或不选”的最优决策。
3. **不同路径**：练习二维网格状态与一维压缩。
4. **零钱兑换**：练习最小值 DP 和不可达状态。
5. **最大子数组和**：练习“以 i 结尾”的状态定义与 Kadane 滚动变量。
6. **最长递增子序列**：练习子序列 DP 中向所有前序状态枚举转移。

## 4. 从打家劫舍理解选择

处理第 i 家时只有两种方案：

- 不偷第 i 家，答案保持前 i-1 家的最优值；
- 偷第 i 家，就不能偷 i-1，答案为前 i-2 家最优值加当前金额。

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

转移方程本质上是在穷举最后一步的所有合法选择，并取最优。

## 5. 网格 DP 与空间压缩

不同路径中，当前格子只依赖上方和左方。二维写法最直观，熟悉后可以压成一维：

```python
dp = [1] * columns
for row in range(1, rows):
    for column in range(1, columns):
        dp[column] += dp[column - 1]
```

更新前的 `dp[column]` 是上方，更新后的 `dp[column - 1]` 是左方。

## 6. 不可达状态

零钱兑换求最小值时，未计算位置不能初始化为 0，否则会被误认为“不需要硬币”。应使用足够大的哨兵值，例如 `amount + 1`。

求最大值时常用负无穷，求最小值时常用正无穷。哨兵值必须不会和合法答案混淆。

## 7. 常见错误

- 状态定义与数组下标含义不一致；
- 初始值看似方便，但不符合定义；
- 转移时漏掉一种选择；
- 遍历顺序导致读取尚未计算或已经被覆盖的状态；
- 把贪心当作 DP，未经证明就选择当前最大值；
- 空数组时直接访问第一项。
