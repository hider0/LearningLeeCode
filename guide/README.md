# 初学者分章学习手册

这套手册把训练器中的 7 个章节拆成独立教程。建议不要一次读完，而是按照“读一点、写一点、复盘一点”的节奏学习。

## 推荐使用方式

每道题按下面六步完成：

1. **先复述题意**：明确输入、输出和边界条件。
2. **写出最直接的办法**：即使是 O(n²) 暴力解，也先确保思路正确。
3. **识别章节模式**：哈希、双指针、快慢指针、栈、递归、DP 或二分。
4. **独立编码并提交**：卡住时先看第一条提示，不要直接展开题解。
5. **记录错误类型**：区分“没有思路”“边界漏掉”“代码写错”“复杂度过高”。
6. **隔天重做**：不看旧代码，从空白模板重新写一遍。

## 学习顺序

| 阶段 | 章节 | 目标 |
|---|---|---|
| 基础数据处理 | [数组与哈希](01-array-hash.md)、[字符串](02-string.md) | 熟悉遍历、字典、集合和双指针 |
| 指针与容器 | [链表](03-linked-list.md)、[栈](04-stack.md) | 学会维护状态和操作顺序 |
| 递归与搜索 | [二叉树](05-binary-tree.md)、[二分查找](07-binary-search.md) | 掌握递归定义和区间不变量 |
| 综合优化 | [动态规划](06-dynamic-programming.md) | 从暴力递归推导状态转移 |

## 四周入门计划

- **第 1 周**：数组与哈希、字符串。每天 1～2 题，重点练习字典、集合、左右指针。
- **第 2 周**：链表、栈。所有链表题先画图，所有栈题先手动模拟一次。
- **第 3 周**：二叉树、二分查找。每天口述递归终止条件或二分区间含义。
- **第 4 周**：动态规划与综合复习。先写状态定义，再写代码；重做全部错题。

## 是否真正掌握

一道题至少满足以下条件，才算“会了”：

- 能不看答案说出为什么选择该数据结构；
- 能解释循环或递归中的不变量；
- 能独立写出主流程，并处理空输入、单元素等边界；
- 能说出时间和空间复杂度；
- 一周后仍能独立完成同类题。
