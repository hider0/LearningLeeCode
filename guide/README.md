# 初学者分章学习手册

这套手册把训练器中的 7 个章节拆成独立教程。建议不要一次读完，而是按照“读一点、写一点、复盘一点”的节奏学习。

## 如果你是零基础，从这里开始

“零基础”指没写过代码、或只学过一点语法但没刷过算法题。按下面路线走，不要跳步：

1. **第 0 步 · 学最小 Python 知识**（2～3 小时）：读 [Python 零基础速成](python-basics.md)，只学刷题用得上的语法，并完成文末 3 道自测。
2. **第 1 步 · 读懂训练器**：看下面的「训练器与判题规则」，知道代码写在哪、怎么算对。
3. **第 2 步 · 建立复杂度直觉**：看下面的「复杂度通俗入门」，能分清快和慢即可。
4. **第 3 步 · 按章节推进**：每章先读教程的「学前准备」和正文，再按「题目阶梯」顺序做题。

中途卡住是正常且必然的，处理方法见「卡住怎么办」。

## 训练器与判题规则

启动训练器后（见根目录 [README](../README.md)），在浏览器里选章节、选题、写代码、点提交。几条规则值得提前知道：

- **代码写在哪**：每题给出 `class Solution` 模板，你只需填写方法体并用 `return` 返回答案，不要改类名和方法名；
- **怎么算对**：判题器会把你的答案和预期答案比较。绝大多数题要求完全一致；个别题目标明“可按任意顺序返回”，这类题判题时对顺序不敏感；
- **链表和树怎么表示**：题面里链表 `[1,2,3]`、二叉树层序数组 `[3,9,20,null,null,15,7]` 只是**展示形式**，判题器会自动把它们转换成真正的节点对象传给你的代码，你按节点（`node.val`、`node.next`、`node.left`、`node.right`）操作即可，返回时也直接返回节点；
- **可以用 print 调试**：代码里的 `print(...)` 输出会显示在判题结果中，这是新手排查问题最顺手的工具；
- **判题不看写法优劣**：只要输出对就算过。所以“先写暴力解跑通，再优化”完全可行，而且是推荐节奏。

## 复杂度通俗入门

复杂度描述的是“输入变大时，程序变慢/变耗内存的速度”，用大 O 记号表示。入门阶段只需建立这张表的直觉（以 n = 一万个元素为例）：

| 复杂度 | 俗称 | 一万个元素时 | 典型操作 |
|---|---|---|---|
| O(1) | 常数 | 一瞬间 | 字典/集合的查询 |
| O(log n) | 对数 | 约 14 步 | 二分查找 |
| O(n) | 线性 | 一万步 | 遍历一遍数组 |
| O(n log n) | — | 十几万步 | 排序 |
| O(n²) | 平方 | 一亿步，开始吃力 | 双重循环枚举所有数对 |

**经验法则**：n 到几万以上时，O(n²) 的暴力解通常会超时，需要哈希表、二分、动态规划等手段降复杂度。每道题提交后，试着说出自己代码的时间和空间复杂度——题解的讲解部分都有对照。

## 每道题的六步打法

1. **先复述题意**：明确输入、输出和边界条件（空输入？单元素？重复元素？负数？）。把示例在纸上手动推一遍；
2. **写出最直接的办法**：即使是 O(n²) 暴力解，也先确保思路正确、能通过判题；
3. **识别章节模式**：哈希、双指针、快慢指针、栈、递归、DP 或二分；
4. **独立编码并提交**：卡住时先看第一条提示，不要直接展开题解；
5. **记录错误类型**：区分“没有思路”“边界漏掉”“代码写错”“复杂度过高”；
6. **隔天重做**：不看旧代码，从空白模板重新写一遍。能独立重写，才是真会了。

## 卡住怎么办

- 给自己 **30～60 分钟**专注思考；仍然没思路，就看提示、再看讲解，这不丢人——很多题考的是“见过的模式”，第一次见想不出来很正常；
- 看完讲解**不要复制粘贴**：理解思路后关掉答案，自己从空白重新写一遍，写不出来说明还没真懂；
- **不要背题**。背下来的解法会迅速遗忘，也练不出举一反三的能力；要记的是“为什么这样做”和“哪一步是关键洞察”；
- 一道题值不值，不看数量看深度：彻底吃透 50 题，胜过囫囵刷 500 题。

## 四周入门计划

- **第 0 周（零基础加设）**：读 [Python 零基础速成](python-basics.md)，完成自测；
- **第 1 周**：数组与哈希、字符串。每天 1～2 题，重点练习字典、集合、左右指针；
- **第 2 周**：链表、栈。所有链表题先画图，所有栈题先手动模拟一次；
- **第 3 周**：二叉树、二分查找。每天口述递归终止条件或二分区间含义；
- **第 4 周**：动态规划与综合复习。先写状态定义，再写代码；重做全部错题。

## 新手常见问题

- **“第一题就卡住，是不是不适合学编程？”** 不是。几乎所有人入门期都这样，坚持过前 20 题会明显变顺。
- **“要用什么语言刷题？”** 本训练器固定用 Python——它语法最简洁，正好让初学者把注意力放在算法而不是语法上。
- **“需要先系统学一遍数据结构再刷题吗？”** 不需要。每章教程就是该章数据结构的入门材料，边学边刷效率更高。
- **“做对的题还要再看吗？”** 要。对照题解看有没有更优复杂度，并在一周后重做。

## 是否真正掌握

一道题至少满足以下条件，才算“会了”：

- 能不看答案说出为什么选择该数据结构；
- 能解释循环或递归中的不变量；
- 能独立写出主流程，并处理空输入、单元素等边界；
- 能说出时间和空间复杂度；
- 一周后仍能独立完成同类题。
