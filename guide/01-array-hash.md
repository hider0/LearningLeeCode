# 第 1 章：数组与哈希

## 本章目标

学完本章后，你应该能够：

- 熟练使用 `list`、`set` 和 `dict`；
- 看见“是否存在、出现次数、快速查找、分组”时想到哈希结构；
- 理解“用额外空间换取更快查询”的权衡；
- 分清先查询再写入与先写入再查询的差别。

## 1. 数组题真正考什么

数组本身并不难，难点通常是“遍历时需要记住什么”。如果每处理一个元素，都要回头扫描之前的全部元素，复杂度往往会变成 O(n²)。哈希表的作用，就是把之前见过的信息压缩成可以快速查询的状态。

常见信号：

- “是否出现过” → `set`；
- “出现了几次” → `dict[value] = count`；
- “这个值上次在哪里” → `dict[value] = index`；
- “把同类元素放在一起” → 设计统一的分组 key。

## 2. 三个基础模板

### 存在性集合

```python
seen = set()
for value in nums:
    if value in seen:
        return True
    seen.add(value)
return False
```

### 计数字典

```python
counts = {}
for value in nums:
    counts[value] = counts.get(value, 0) + 1
```

### 值到下标的映射

```python
positions = {}
for index, value in enumerate(nums):
    positions[value] = index
```

## 3. 题目阶梯

1. **存在重复元素**：只关心“见没见过”，用集合。
2. **有效的字母异位词**：从存在性升级到字符计数。
3. **两数之和**：记录“值 → 下标”，查询补数。
4. **字母异位词分组**：为同一类字符串设计统一 key。
5. **前 K 个高频元素**：计数字典的进阶应用，按频率取前 k。
6. **除自身以外数组的乘积**：左右两遍前缀积扫描，体会“遍历时分段记住累积结果”。

建议严格按顺序完成。前两题练习哈希表基本操作，后两题练习如何根据题意设计存储内容。

## 4. 两数之和推导

暴力思路是枚举所有 `(i, j)`，判断 `nums[i] + nums[j] == target`，需要 O(n²)。

遍历到当前值 `x` 时，我们真正想知道的是：之前是否出现过 `target - x`。如果把之前的值和下标存入字典，查询就从 O(n) 降为平均 O(1)。

关键顺序是：

```python
if target - value in seen:
    return [seen[target - value], index]
seen[value] = index
```

必须先查询再写入，否则当 `target == 2 * value` 时，当前元素可能错误地匹配自己。

## 5. 分组 key 的思维

字母异位词的原字符串不同，但排序后相同：`eat`、`tea`、`ate` 都变成 `aet`。这个 `aet` 就是它们的“规范化形式”。

以后遇到分组问题，可以问自己：

> 同一组元素有没有一个完全相同、可哈希的代表形式？

这个思想比具体代码更重要，它还会出现在坐标归类、频率统计、状态压缩等问题中。

## 6. 常见错误

- 用列表做频繁的 `in` 查询，导致整体退化为 O(n²)；
- 两数之和先写入字典，错误匹配当前元素；
- 只比较字符种类，不比较字符次数；
- 使用可变列表作为字典 key；字典 key 必须可哈希，可改成字符串或元组；
- 忘记分析哈希表带来的 O(n) 额外空间。
