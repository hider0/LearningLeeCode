# 第 4 章：栈

## 本章目标

- 理解后进先出（LIFO）；
- 识别配对、嵌套、撤销和“最近未处理元素”问题；
- 掌握普通栈与单调栈；
- 避免弹栈顺序和空栈错误。

## 1. 栈的直觉

栈像一摞盘子：最后放上去的最先取走。Python 通常直接用列表：

```python
stack = []
stack.append(value)  # 入栈
value = stack.pop()  # 出栈
top = stack[-1]      # 查看栈顶
```

看到以下描述时应想到栈：

- 左右符号需要成对匹配；
- 结构有嵌套层级；
- 后出现的操作要先处理；
- 当前元素要解决之前尚未解决的问题。

## 2. 括号匹配

左括号入栈，右括号必须与栈顶左括号匹配。遇到右括号时先检查栈是否为空，否则 `pop()` 会报错。

```python
pairs = {')': '(', ']': '[', '}': '{'}
for char in text:
    if char in pairs:
        if not stack or stack.pop() != pairs[char]:
            return False
    else:
        stack.append(char)
return not stack
```

最后还要检查栈为空，否则像 `"(("` 这样的输入会被误判为正确。

## 3. 表达式求值

逆波兰表达式没有括号，运算符总是作用于它前面的两个结果。遇到数字入栈，遇到运算符弹出右操作数和左操作数：

```python
right = stack.pop()
left = stack.pop()
stack.append(left - right)
```

顺序不能写反，减法和除法不满足交换律。Python 的 `//` 对负数向下取整，而题目通常要求向零截断，应使用 `int(left / right)`。

## 4. 单调栈

单调栈不是为了保存所有元素，而是保存“还没有找到答案”的候选下标，并让栈内对应值保持单调。

每日温度中，栈内温度单调不升。遇到更高温度时，它可以连续解决栈顶若干天：

```python
while stack and temperatures[stack[-1]] < temperature:
    previous = stack.pop()
    answer[previous] = index - previous
stack.append(index)
```

虽然有嵌套 while，但每个下标只入栈、出栈一次，总时间 O(n)。

## 5. 题目阶梯

1. **有效的括号**：理解匹配与栈顶。
2. **简化路径**：把栈当作可撤销的目录序列。
3. **逆波兰表达式求值**：练习操作数顺序。
4. **每日温度**：从普通栈升级到单调栈。

## 6. 常见错误

- 未检查空栈就 `pop()`；
- 最后忘记验证栈是否清空；
- 二元运算的左右操作数顺序颠倒；
- 路径中的 `...` 被错误当作 `..`；
- 单调栈保存值而不是下标，导致无法计算距离；
- 看到 while 就误判为 O(n²)，没有按入栈出栈次数分析。
