# 第 5 章：二叉树

## 本章目标

- 理解根、左右子树、叶子和树高；
- 掌握递归三要素：函数含义、终止条件、子问题组合；
- 区分深度优先搜索（DFS）和广度优先搜索（BFS）；
- 能把层序数组画成树。

## 1. 先学会读树

训练器使用层序数组表示二叉树，例如：

```text
[3, 9, 20, null, null, 15, 7]
```

对应：

```text
      3
     / \
    9  20
      /  \
     15   7
```

开始写代码前先画图，特别注意 `null` 表示缺少结点，而不是值为 0 的结点。

## 2. 递归三问

写递归前回答：

1. **函数返回什么？** 例如 `maxDepth(node)` 返回以 node 为根的树高。
2. **最小问题是什么？** 空树的深度为 0。
3. **如何组合子问题？** 当前深度是 `1 + max(left_depth, right_depth)`。

```python
def maxDepth(node):
    if node is None:
        return 0
    return 1 + max(maxDepth(node.left), maxDepth(node.right))
```

不要在递归过程中同时承担太多职责。函数含义越清晰，递归越容易写对。

## 3. 同步递归

相同的树需要同时比较两个结点：

- 都为空 → 相同；
- 只有一个为空 → 不同；
- 值不同 → 不同；
- 当前相同 → 继续比较左右子树。

这种“两个对象同步向下”的模式还会用于对称树、子树判断等题目。

## 4. BFS 层序遍历

BFS 使用队列。每轮开始时记录当前队列长度，这个长度就是当前层的结点数：

```python
while queue:
    level = []
    for _ in range(len(queue)):
        node = queue.popleft()
        level.append(node.val)
        # 把孩子加入队列
    result.append(level)
```

必须在进入 for 循环前固定长度，因为循环中队列会加入下一层结点。

## 5. 题目阶梯

1. **相同的树**：同步递归和空结点判断。
2. **二叉树的最大深度**：最基础的自底向上递归。
3. **翻转二叉树**：递归修改结构。
4. **二叉树的层序遍历**：从 DFS 过渡到 BFS。

## 6. DFS 与 BFS 怎么选

- 求深度、子树信息、路径性质：优先考虑 DFS/递归；
- 按层输出、寻找最近层级、最短步数：优先考虑 BFS；
- 两者都能做时，选择更贴合输出结构的方法。

## 7. 常见错误

- 忘记空树终止条件；
- 把结点值为 0 当成空结点，错误使用 `if node.val`；
- 递归后忘记返回组合结果；
- 翻转时只交换当前层，没有递归处理子树；
- BFS 在循环过程中使用变化后的队列长度，导致层级混合；
- 对极度倾斜的树忽略递归深度问题。
