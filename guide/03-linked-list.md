# 第 3 章：链表

## 本章目标

- 理解链表结点通过 `next` 连接，而不是连续存储；
- 熟练使用哑节点、前后指针和快慢指针；
- 修改指针前先保存后继，避免链表断裂；
- 能在纸上画出每一步指针变化。

## 1. 为什么链表题容易错

数组下标不会因为读取而改变，但链表一旦修改 `next`，原来的连接可能立即丢失。链表题首先考的是操作顺序，其次才是算法。

建议每道题都画成：

```text
prev <- current -> next_node -> ...
```

每次赋值前问：修改后，我还能不能找到剩余链表？

## 2. 反转链表模板

```python
previous = None
current = head
while current:
    next_node = current.next
    current.next = previous
    previous = current
    current = next_node
return previous
```

四行更新的顺序不能随意交换。第一步保存 `next_node` 是整个算法的安全带。

## 3. 哑节点的用途

当头结点可能变化时，在头部之前增加一个不承载业务数据的 `dummy`：

```python
dummy = ListNode(0)
dummy.next = head
```

这样删除头结点和删除中间结点都变成“修改前驱的 next”，最后统一返回 `dummy.next`。合并链表时也可以用 dummy 保存结果链表的固定起点。

## 4. 快慢指针

### 找中点

slow 每次一步，fast 每次两步。fast 到末尾时，slow 到中间。

### 找倒数第 N 个

fast 先走 N 步，再让 fast 与 slow 同步前进。两者始终保持 N 的距离，fast 到末尾时 slow 就到目标附近。

这两类题的共同点是：用不同速度或固定距离，把“长度信息”编码在两个指针之间。

## 5. 题目阶梯

1. **链表的中间结点**：最简单的快慢指针。
2. **反转链表**：练习保存后继和改变方向。
3. **合并两个有序链表**：练习 dummy 和尾指针。
4. **删除倒数第 N 个结点**：综合 dummy 与固定距离双指针。

## 6. 合并链表的不变量

维护 `tail` 指向结果链表最后一个结点。每轮从两个链表头部选较小者接到 tail 后面，然后移动被选中的链表和 tail。

循环中始终保证：

- dummy 到 tail 是已经排好序的结果；
- `list1` 和 `list2` 指向尚未处理部分；
- 尚未处理部分仍各自有序。

理解不变量后，代码就不再是死记硬背。

## 7. 常见错误

- 反转时先改 `current.next`，却没有保存原后继；
- 合并后忘记把剩余非空链表整体接上；
- 删除头结点时写大量特判，而没有使用 dummy；
- 快指针先走的步数差一位；
- 返回旧 head，而不是 `previous` 或 `dummy.next`。

## 8. 手动测试数据

链表题至少测试：

- 空链表；
- 单结点；
- 两个结点；
- 操作发生在头部；
- 操作发生在尾部；
- 奇数长度与偶数长度。
