# 第 7 章：二分查找

## 本章目标

- 理解二分查找依赖“有序”或“单调条件”；
- 掌握闭区间与左闭右开区间模板；
- 用区间不变量避免死循环和差一错误；
- 从查找具体值扩展到查找边界和旋转点。

## 1. 二分查找的本质

二分并不只是“在排序数组里找数字”。它真正需要的是：检查一个位置后，能够确定其中一侧全部不可能是答案，从而一次排除一半搜索空间。

判断能否二分时问：

> 有没有一个条件，随着位置变化呈现从 false 到 true，或从 true 到 false 的单调变化？

## 2. 闭区间模板

区间 `[left, right]` 两端都可能是答案：

```python
left = 0
right = len(nums) - 1
while left <= right:
    mid = left + (right - left) // 2
    if nums[mid] == target:
        return mid
    if nums[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
return -1
```

因为 mid 已经检查过，更新时必须使用 `mid + 1` 或 `mid - 1`，否则区间可能无法缩小。

## 3. 左闭右开模板

寻找第一个满足条件的位置时，常使用 `[left, right)`：

```python
left = 0
right = len(nums)
while left < right:
    mid = left + (right - left) // 2
    if nums[mid] < target:
        left = mid + 1
    else:
        right = mid
return left
```

这里 right 本身不属于搜索区间，因此可以初始化为 `len(nums)`，也自然表示“应插入到数组末尾”。

## 4. 题目阶梯

1. **二分查找**：找具体目标值，练闭区间。
2. **搜索插入位置**：找第一个大于等于目标的位置，练边界二分。
3. **旋转数组中的最小值**：用比较关系判断答案所在半区。
4. **搜索旋转排序数组**：先判断哪半区有序，再决定 target 在哪半区。
5. **寻找峰值**：利用相邻元素的大小关系沿着上坡方向二分。

## 5. 区间不变量

不要只背代码，要说清楚循环开始时什么始终成立。

闭区间版本：

> 如果答案存在，它一定在 `[left, right]` 中。

左闭右开版本：

> 第一个满足条件的位置一定在 `[left, right]` 中，包括最终可能等于数组长度的 right。

每次更新都必须保持这句话继续为真。

## 6. 旋转数组如何判断

比较中点与最右端：

- `nums[mid] > nums[right]`：mid 在较大的左片段，最小值严格位于右侧；
- 否则：mid 位于包含最小值的片段，最小值可能就是 mid，所以保留 mid。

注意本题元素互不相同。如果允许重复，`nums[mid] == nums[right]` 时无法确定方向，需要额外处理。

## 7. 常见错误

- 混用两种区间定义；
- `while left < right` 与 `while left <= right` 随意替换；
- 更新成 `left = mid`，导致两个元素时死循环；
- 找边界时目标一出现就返回，错过更靠左的答案；
- 没有单调性也强行使用二分；
- 空数组时没有明确返回约定。

## 8. 手动模拟方法

用长度为 1 和 2 的数组检查模板：

```text
[5], target = 5
[1, 3], target = 2
[1, 3], target = 4
```

如果模板会死循环或返回越界位置，小数组通常能立刻暴露问题。
